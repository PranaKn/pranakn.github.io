# Cybersecurity Newsfeed

## 📅 04/11/26

## 🛡️ Vulnerabilities

- **WordPress Core Race Condition (CVE-2026-119977)**: CISA added CVE-2026-119977 to its Known Exploited Vulnerabilities Catalog affecting WordPress Core versions 4.7 through 7.1.3. The flaw stems from predictable, web-accessible staging paths during updates, allowing unauthenticated remote attackers to execute arbitrary code. [More info](https://www.cisa.gov/known-exploited-vulnerabilities-catalog?search_api_fulltext=CVE-2026-119977)

- **Barracuda ESG Critical Vulnerability Chain (CVE-2026-116606 & CVE-2026-111560)**: Critical flaws in Barracuda Email Security Gateway can be chained to gain unauthorized root access via a pre-authentication authorization bypass and an OS command injection flaw. [More info](https://thehackernews.com/2026/11/barracuda-flaws-could-be-chained-to.html) | [More info](https://www.bleepingcomputer.com/news/security/barracuda-warns-of-critical-flaws-allowing-root-access-to-devices/)

- **Node-RED ICS Authentication Flaw (CVE-2026-58115)**: Threat actors are actively exploiting a CVSS 10.0 vulnerability in Node-RED environments integrated into industrial control system (ICS) devices to execute arbitrary commands and deploy Linux botnet malware. [More info](https://www.helpnetsecurity.com/2026/11/03/node-red-cve-2026-58115-exploitation/)

- **Red Hat Linux Kernel TCP Stack RCE (CVE-2026-98432)**: Red Hat issued patches for a CVSS 9.8 critical Linux kernel TCP stack vulnerability that allows unauthenticated remote attackers to trigger memory corruption and achieve root remote code execution via crafted IPv4 requests. [More info](https://thehackernews.com/2026/11/red-hat-patches-98-rated-linux-tcp-rce.html)

## 🎯 Adversaries

- **Binance Breached via Fake Job Interviews**: Cryptocurrency exchange Binance disclosed a social engineering attack where malicious actors impersonated headhunters during a multi-stage technical assessment to deploy a trojanized payload, facilitating a $63 billion crypto theft. [More info](https://www.bleepingcomputer.com/news/security/binance-says-fake-job-interview-led-to-63-billion-crypto-heist/) | [More info](https://thehackernews.com/2026/11/binance-reveals-how-fake-job-interviews.html)

- **LLMjacking Cloud AI Resources Surge**: Threat actors are targeting cloud environments with stolen credentials to provision GPU instances for unauthorized LLM workloads, incurring over $1 million in unauthorized AI API charges for victim organizations. [More info](https://www.bleepingcomputer.com/news/security/google-llmjacking-attacks-rack-up-1-million-in-cloud-ai-charges/) | [More info](https://www.darkreading.com/cloud-security/llmjacking-thriving-cybercriminal-enterprise)

- **Trojanized Software Installers via Malicious Ads**: Microsoft published research detailing an active ad campaign distributing trojanized software downloads containing ad-injectors, info-stealers, and crypto miners signed with valid digital certificates. [More info](https://www.microsoft.com/en-us/security/blog/2026/11/03/fake-download-campaign-uses-trojanized-installers-deliver-monetization-payloads/)

- **3am Ransomware Hits UK Educational Systems**: The 3am ransomware group used automated AI-driven scanning tools to rapidly identify perimeter vulnerabilities and execute lateral movement across UK school system networks. [More info](https://hackread.com/3am-ransomware-uk-school-systems-ai-attack/)

- **CPGuard Server Security Update Hijacking**: Attackers compromised CPGuard's software update delivery infrastructure to push tampered binaries containing backdoors with administrative execution privileges. [More info](https://thehackernews.com/2026/11/cpguard-update-channel-hijacked-to.html)

- **Pre-Installed Backdoor on 1.3M Android TV Boxes**: Security analysts uncovered a persistent firmware backdoor active on over 1.3 million Android-based TV set-top boxes, enlisting them into a global botnet for DDoS operations and proxy routing. [More info](https://www.malwarebytes.com/blog/mobile/2026/11/a-hidden-backdoor-put-1-3-million-tv-boxes-to-work-for-criminals)

- **SSH Backdoors Hidden in Cursor & Claude Code Extensions**: Malicious extensions targeting developer environments silently deploy scripts designed to extract local SSH keys, user credentials, and active terminal session tokens. [More info](https://hackread.com/cursor-claude-code-extensions-ssh-backdoor-code/)
