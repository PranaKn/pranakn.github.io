# Cybersecurity Newsfeed

## 📅 14/10/26

## 🛡️ Vulnerabilities

- **Qualys Patch Tuesday October 2026 Review**: Qualys published its analysis of Microsoft’s latest update cycle, addressing critical remote code execution and privilege escalation flaws across Windows, Office, and server components. The breakdown provides impact metrics and prioritized mitigation strategies for enterprise teams. [More info](https://blog.qualys.com/vulnerabilities-threat-research/2026/10/13/microsoft-patch-tuesday-october-2026-security-update-review)

- **Ghostscript PDF Interpreter RCE Flaw**: A critical input validation flaw in the open-source Ghostscript interpreter allows unauthenticated remote attackers to escape the execution sandbox via uploaded PDF files, leading to full server compromise. [More info](https://www.bleepingcomputer.com/news/security/ghostscript-flaw-lets-hackers-hijack-servers-via-pdf-uploads/)

- **CISA Adds Windows & Ivanti Flaws to KEV Catalog**: CISA added a Windows command injection bug (CVE-2026-96951) and an Ivanti Connect Secure spoofing authentication bypass (CVE-2026-104935) to its KEV catalog, requiring federal agencies to remediate under BOD 26-04. [More info](https://www.cisa.gov/news-events/alerts/2026/10/13/cisa-adds-two-known-exploited-vulnerabilities-catalog)

- **Microsoft October 2026 Patch Tuesday Fixes 1,411 Flaws**: Microsoft addressed 1,411 vulnerabilities across its ecosystem, including three zero-day bugs—one of which is actively exploited in the wild alongside two publicly disclosed flaws. [More info](https://www.bleepingcomputer.com/news/microsoft/microsoft-october-2026-patch-tuesday-fixes-1-411-flaws-3-zero-days/)

- **Ivanti Connect Secure Exploit Chain**: Threat actors are chaining three distinct flaws—authentication bypass, privilege escalation, and command injection—in Ivanti Connect Secure VPN appliances to execute remote code and move laterally across networks. [More info](https://thehackernews.com/2026/10/attacker-chains-three-ivanti-connect.html)

- **Maximum-Severity SAP System Command Flaw**: SAP released security updates for a CVSS 10.0 vulnerability caused by missing authentication and access checks, allowing unauthenticated attackers to execute arbitrary system commands. [More info](https://thehackernews.com/2026/10/sap-discloses-critical-cvss-10-flaw-in.html)

- **LiteLLM AI Gateway Hijack & Key Exfiltration Flaws**: Check Point Research uncovered two flaws (CVE-2026-35029, CVE-2026-59823) in LiteLLM allowing low-privileged users to hijack admin accounts, execute remote code, and steal API keys for OpenAI and Anthropic. [More info](https://www.itsecurityguru.org/2026/10/13/litellm-flaws-let-low-privileged-users-hijack-ai-gateway-and-steal-provider-keys/)

- **Adobe Patches 140 Vulnerabilities Across 10 Products**: Adobe issued updates fixing 140 bugs in products including Photoshop, Acrobat, and Reader, resolving multiple critical issues that could lead to code execution and privilege escalation. [More info](https://www.securityweek.com/adobe-patches-140-vulnerabilities-across-10-products/)

- **Ivanti Warns of Connect Secure Zero-Day**: Ivanti issued an urgent warning for an actively exploited zero-day vulnerability impacting Connect Secure VPN appliances, allowing remote execution of arbitrary commands. [More info](https://www.bleepingcomputer.com/news/security/ivanti-warns-of-connect-secure-zero-day-exploited-in-attacks/)

- **Docker Hub User Impersonation & Image Tampering**: A flaw in Docker Hub enabled malicious actors to impersonate legitimate users and manipulate published container image repository tags, posing supply chain risks. [More info](https://www.bleepingcomputer.com/news/security/docker-hub-flaw-let-attackers-impersonate-users-tamper-with-images/)

- **Critical SSRF Security Flaw in SAP OAuth2**: SAP warned of a CVSS 10.0 Server-Side Request Forgery vulnerability in its OAuth2 implementation that lets unauthenticated remote attackers access restricted internal endpoints. [More info](https://www.bleepingcomputer.com/news/security/sap-warns-of-maximum-severity-oauth2-ssrf-security-flaw/)

- **MarkLogic Enterprise NoSQL Critical Flaws**: Two critical vulnerabilities in MarkLogic Enterprise NoSQL database software allow unauthenticated attackers to execute code with elevated privileges via administrative endpoints. [More info](https://thehackernews.com/2026/10/two-critical-marklogic-flaws-could-give.html)

- **GitLab Emergency Patch for CVSS 10.0 Flaw**: GitLab released an emergency security patch addressing a maximum-severity command execution and account takeover bug in self-managed DevOps instances. [More info](https://thehackernews.com/2026/10/gitlab-patches-cvss-100-flaw-that-could.html)

- **SonicWall SMA Max-Severity SSRF Exploitation**: A maximum-severity SSRF vulnerability impacting SonicWall Secure Mobile Access (SMA) appliances is under active exploitation, allowing remote control bypass. [More info](https://www.darkreading.com/vulnerabilities-threats/max-severity-ssrf-flaw-sonicwall-sma-devices-under-attack)
