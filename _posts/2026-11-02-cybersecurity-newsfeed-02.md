# Cybersecurity Newsfeed

## 📅 02/11/26

## 🛡️ Vulnerabilities

- **TeamViewer Vulnerability Lets Attackers Run Code on IT Support Staff's PCs**: Cybersecurity firm Remedio disclosed a critical vulnerability in TeamViewer that allows remote attackers to execute arbitrary code on an IT support technician's local machine immediately once an incoming remote-control connection is accepted. TeamViewer released security updates to fix the flaw. [More info](https://hackread.com/teamviewer-vulnerability-code-it-support-staff-pcs/)

- **Alpine Linux Rebuilds GitLab After Attempted RCE Attack**: Alpine Linux completely rebuilt its GitLab server infrastructure and issued global password resets following an attempted remote code execution (RCE) attack targeting CVE-2026-97229. Forensic investigation confirmed release binaries and signing keys remained uncompromised. [More info](https://www.bleepingcomputer.com/news/security/alpine-linux-rebuilds-gitlab-after-attempted-rce-attack/)

- **A Shared ChatGPT Link Could Run Arbitrary Code on Users' Computers**: Security researchers identified a high-severity flaw in ChatGPT's shared link rendering mechanism that could allow threat actors to execute remote code on visiting user systems. OpenAI released a server-side hotfix to sanitize shared conversation contexts. [More info](https://thehackernews.com/2026/10/a-shared-chatgpt-link-could-run.html)

- **SS7 and Diameter Attacks: How Signaling Flaws Expose Your Phone**: A technical security analysis highlights persistent architectural vulnerabilities within legacy SS7 and modern Diameter telecommunications signaling protocols, enabling cellular location tracking, SMS interception, and 2FA code hijacking without target interaction. [More info](https://www.bleepingcomputer.com/news/security/ss7-and-diameter-attacks-how-signaling-flaws-expose-your-phone/)

- **Fake GitHub Repo Tricks AI Agents Into Installing SolanaCry Malware**: AIR Research Lab identified a malicious campaign deploying a fake GitHub repository disguised as a Solana development kit to trick automated AI coding agents into installing SolanaCry malware via NetSupport Manager binaries. [More info](https://hackread.com/fake-github-repo-ai-coding-agents-solanacry-malware/)

- **NetamLoader Malware Targets Government Windows 10 Systems in Asia**: A novel malware strain named NetamLoader exploits AppDomainManager injection by abusing PatchMyPC-ScriptRunner.exe to sideload rogue DLLs and execute multi-stage payloads against Asian government entities. [More info](https://thehackernews.com/2026/11/netamloader-malware-targets-government.html)

- **Chinese Hackers Use AI-Powered ARTEX to Target Critical Infrastructure**: Chinese state-sponsored threat actors are deploying an AI-powered framework named ARTEX to automate network reconnaissance, evaluate system vulnerabilities, and craft tailored spear-phishing lures against critical infrastructure targets. [More info](https://thehackernews.com/2026/10/chinese-hackers-use-ai-powered-artex-to.html)

- **Hugging Face Malware Campaign Returns to Hijack GPUs for Crypto Mining**: Attackers uploaded trojanized machine learning models to Hugging Face containing malicious scripts that execute automatically during model loading to hijack GPU resources for unauthorized cryptocurrency mining. [More info](https://www.bleepingcomputer.com/news/security/hugging-face-malware-campaign-returns-to-hijack-gpus-for-crypto-mining/)
