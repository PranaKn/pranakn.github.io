# Cybersecurity Newsfeed

## 📅 19/10/26

## 🛡️ Vulnerabilities

- **SiteGuard WAF OS Command Injection**: Threat actors are actively exploiting a critical OS command injection vulnerability in JP-Secure SiteGuard Server Edition. The flaw allows remote unauthenticated attackers to execute arbitrary commands with root or SYSTEM privileges. [More info](https://www.bleepingcomputer.com/news/security/hackers-exploit-siteguard-waf-flaw-to-run-commands-as-system-root/)

- **Critical RCE Flaws Patched in Drupal**: Drupal released security updates addressing two critical remote code execution vulnerabilities (CVE-2026-108097 and CVE-2026-108099) in its Field UI and Entity List modules. Public exploit code could emerge rapidly. [More info](https://www.bleepingcomputer.com/news/security/drupal-patches-critical-rce-flaws-warns-exploits-may-emerge-soon/)

- **Adobe Commerce & Magento BlockStrap Flaw (CVE-2026-103849)**: A maximum-severity vulnerability in the BlockStrap library allows unauthenticated remote attackers to achieve arbitrary PHP code execution on e-commerce platforms. [More info](https://www.bleepingcomputer.com/news/security/critical-blockstrap-flaw-lets-hackers-run-code-on-magento-servers/)

- **CISA Adds Fortinet and BeyondTrust Flaws to KEV**: CISA added CVE-2025-61624 (Fortinet path traversal) and CVE-2026-102764 (BeyondTrust Remote Support authentication bypass) to its Known Exploited Vulnerabilities catalog. [More info](https://www.cisa.gov/news-events/alerts/2026/10/16/cisa-adds-two-known-exploited-vulnerabilities-catalog)

- **Critical Flaws Patched by F5 and Juniper Networks**: F5 addressed 11 NGINX vulnerabilities (including unauthenticated RCEs), while Juniper Networks resolved over 150 defects across Junos OS and Junos OS Evolved. [More info](https://www.securityweek.com/f5-juniper-networks-patch-critical-vulnerabilities/)

- **PeerStitch Malware Hijacks Over 500 Enterprise Firewalls**: Attackers compromised FortiManager management instances to deploy the PeerStitch P2P botnet mesh across connected FortiGate devices. [More info](https://securityaffairs.com/201077/malware/peerstitch-malware-how-attackers-compromised-500-firewalls-through-fortimanager.html)

- **Krybit Ransomware Targets Enterprise Infrastructure**: Analysis from Fortra details double-extortion tactics, credential abuse, and living-off-the-land techniques deployed by Krybit ransomware operators. [More info](https://www.fortra.com/blog/krybit-ransomware-what-you-need-know)

- **Israeli Ad Tech Ecosystem Used to Deliver Candiru Spyware**: An Israeli advertising agency functioned as an operational delivery channel, leveraging zero-click malicious ads to deploy Candiru surveillance malware on target devices. [More info](https://www.securityweek.com/israeli-ad-firm-doubled-as-candirus-zero-click-spyware-delivery-channel/)

- **An Garda Síochána Twitter Account Hijacked for Crypto Scam**: Cybercriminals compromised the official Twitter account of Ireland's national police force to direct followers to wallet-draining phishing sites. - **Fake AI Desktop Applications Target Developers**: Phishing campaigns impersonating ChatGPT and Claude desktop apps trick developers into downloading trojanized installers that deliver infostealers. [More info](https://www.darkreading.com/application-security/fake-claude-chatgpt-attacks-developers-risk)
